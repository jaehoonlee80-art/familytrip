🎪 프로그램

1. 메인프로그램 슈퍼스타 콘테스트 '오디세이' : 자신을 드러내고 도전을 꿈꾸는 모든 청년들에게 무대의 기회를 제공하는 음악퍼포먼스 프로그램. 선발된 참가팀의 퍼포먼스 공연이 이어진다. 과천 청년의 날 기념식 : 한 해 동안의 과천 청년 활동을 기념하는 공식 행사로 개회 선언, 내외빈 축사, 올해의 과천청년 유공자 표창, 개막 퍼포먼스로 구성된다. 초청 아티스트 공연 : 기념식 뒤 바로 이어지는 야간 공연. 다수의 초청 아티스트가 무대에 올라 축제의 피날레를 장식한다. 낭만 버스킹 무대 : 메인무대와 별도로 운영되는 상설 공연 무대. 브라스밴드, 어쿠스틱, 버블쇼 등 형형색색의 버스킹 팀들이 릴레이 공연을 펼친다. 2. 부대프로그램 청정Zone : (전시 홍보부스) 과천시 청년정책과 유관기관을 한자리에서 만나는 참여형 부스. (청년라운지) 과천시 청년공간 비행지구, 과천청년네트워크가 운영하는 체험형 정책참여부스. 과몰입Zone : (리워드&체험 프로그램) 방문객이 직접 손으로 만들고 참여하는 체험존. 밤토리 캐리커쳐, 출력타투샵, 나만의 음료자판기(과일음료/복분자)를 운영한다. 과충전Zone : (팝업스토어) 평소 과천에서 접하기 어려운 공간을 하루 동안 개방하는 팝업존. 방전검사실, 충전오락실, 에너지낚시터를 운영하여 '방전금지구역' 컨셉의 체험형 프로그램을 진행한다. 플리마켓 : 청년 셀러들이 참여하는 소규모 마켓. 수공예품과 개성 있는 물품을 판매한다. 힐링존 : 그늘막과 빈백, 테이블이 마련된 쉼터. 축제 관람 중 자유롭게 휴식할 수 있는 공간이다. 3. 소비자 참여 프로그램 스탬프투어 : 중앙공원 내 각 존을 돌며 도장을 모으는 참여 이벤트. 과충전Zone, 청정Zone의 지정 부스를 방문해 스탬프를 완성하면 굿즈 뽑기 기회가 주어진다. 굿즈 뽑기 이벤트 : 스탬프투어 완주자를 대상으로 진행되는 리워드 이벤트. 캡슐추첨기를 돌려 굿즈를 뽑아 가는 참여형 리워드로 운영된다. SNS 인증 캠페인 : 스탬프투어 완주자를 대상으로 운영되는 추가 이벤트. 행사장 입구 아치에서 사진을 촬영해 축제 공식 계정을 태그하고 지정 해시태그와 함께 게시물 업로드 시 운영부스에서 확인 후 굿즈를 증정한다. 관람객 설문 이벤트 : 축제 만족도 설문에 참여한 방문객을 대상으로 추첨을 통해 기프티콘을 제공한다. 4. 기타 내용 과식Zone : 푸드트럭 운영 : 야끼소바, 닭꼬치, 크레페, 타코야끼 등 다양한 먹거리를 판매하는 푸드트럭이 운영된다. 전 부스에서 다회용기를 사용해 친환경 축제를 지향한다. 야간 경관 연출 : 해가 진 뒤 스트링전구로 공원에 특정 스팟을 밝혀 축제에 아름다운 분위기를 조성한다. 운영 및 편의 : 관람객이 안전하고 편하게 즐길 수 있도록 행사장 내 운영부스와 안내데스크, 의료부스를 운영한다.
