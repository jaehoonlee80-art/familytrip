여행 환율 계산기 — 실시간 환율로 여행 경비 즉시 환산

원화와 주요 여행지 통화를 실시간 환율로 변환합니다. 여행 경비를 출발 전 현지 화폐로 미리 계산해보세요. 데이터는 매일 갱신되는 무료 환율 API 기준입니다.

가족여행 경비 계산기 — 지역·인원·일정·예산 범위로 총예산 자동 예측

여행지·출발지·일정·인원·예산 범위(실속/균형/고급)만 고르면 항공·숙소·식비·활동비를 자동 추정. 출발일별 예상 비용과 패키지별 비교까지 한눈에.

짐싸기 리스트 생성기 — 목적지·계절·아이 수에 맞춰 자동 체크리스트

여행지와 계절, 아이 수, 여행 일수를 고르면 필요한 짐 목록이 자동으로 만들어지는 무료 도구. 체크박스로 하나씩 확인하고 진행률을 저장합니다.

항공권 최저가 알림 — 목표가 도달 시 이메일로 알려드립니다

여행지·출발 월·목표가를 설정하면 6시간마다 항공권 운임을 확인해 목표 가격 이하로 떨어지면 이메일로 알려주는 무료 최저가 알림 서비스. Going.com 방식을 무료로 제공합니다.

여행 D-day 계산기 — 출발일·여행지·준비 타임라인 자동 표시

여행 출발일과 여행지를 입력하면 D-day를 계산하고, 항공권·숙소·짐싸기·여권 준비 등 지금 해야 할 준비 타임라인을 자동으로 보여줍니다.

여행 가기 전 꼭 궁금한 질문 30가지 — 서류·환전·날씨·아이동반 총정리

여행 준비 중 가장 많이 묻는 질문 30가지를 출국 서류, 환전, 날씨 확인, 현지 교통, 아이 동반, 통신·전자기기, 건강·안전, 경비로 나눠 한 번에 답합니다.

여행지 실시간 날씨 — 제주·오키나와·도쿄 지금 기온과 강수

제주·오키나와 나하·후쿠오카·도쿄·오사카의 실시간 날씨를 한 화면에서 확인. 기온·체감온도·강수·풍속을 자동 갱신합니다.

여행 코스 생성기 — 지역·인원·여행 스타일별 맞춤 일정

여행 지역, 성인·소아 인원, 여행 스타일, 기간(1일/2-3일/4-5일/1주일)을 선택하면 일차별 관광 코스를 자동으로 만들어주는 무료 도구. 세계 100개 도시 데이터 기반.
