전국 관광명소 100선 + 실시간 CCTV — 가기 전에 현장 확인

여행 가기 전에 지금 그곳이 어떤지 확인할 수 있는 명소 100곳입니다. 공공 CCTV가 실제로 송출되는 곳은 아래에서 바로 화면을 보고, 송출이 없는 곳은 공식 포털 확인 방법을 안내합니다.

원칙: 송출이 확인된 카메라만 연결합니다. 명소 "근처" 카메라가 있는 경우 인근이라고 표시하고, 전용 카메라가 없는 명소는 억지로 연결하지 않습니다.

실시간 화면 보는 법

  • 제주 카메라: 60초마다 자동 갱신되는 최신 캡처입니다 (원본: 펀제주 공개 스냅샷).
  • 국립공원: 실제 WebRTC 라이브 스트림 — 카드가 화면에 보일 때 자동 재생됩니다. 데이터 사용량이 크니 Wi-Fi 권장.
  • 옹진군: 5분마다 GitHub Actions가 실제 CCTV 프레임을 캡처해 자동 갱신합니다.

전국 관광명소 100선 — CCTV 연결 현황

공항·항만·산업시설 실시간 CCTV

인천항 진입도로·컨테이너터미널 — 13개 지점 (5분 갱신)

공항 주변 실시간 영상 — 경기도교통정보센터 인천공항영업소

공항 내부 활주로 CCTV는 비공개입니다. 이 화면은 인천공항고속도로·공항영업소 주변 도로의 공식 실시간 영상입니다. 김포공항·김해공항 주변은 각 시도 교통정보센터에서 확인하세요.

기타 항만·해양 CCTV

  • 부산항·여수항·울산항·목포항 등: 국립해양조사원 해무 CCTV는 방송사 제공용이라 일반 공개가 제한됩니다. 공공데이터포털의 해무 CCTV 스틸컷 API(무료 키 발급)로 수집 가능합니다.
  • 인천항: 이 페이지 상단의 인천항 13개 지점 스냅샷이 공식 공개 영상입니다.

자주 묻는 질문

명소마다 CCTV가 있나요?

아니요. 공공 CCTV는 재난·교통·안전 목적이라 관광명소 전용 카메라는 많지 않습니다. 현재 확인된 송출은 제주 공공 CCTV, 국립공원 19개 지점, 옹진군 서해 섬 42대, 재난포털 약 45개 지점입니다. 나머지 명소는 각 시도 교통정보센터의 도로 CCTV로 간접 확인 가능합니다.

화면이 자동으로 갱신되나요?

제주(60초)·옹진군(5분)은 스냅샷 자동 갱신, 국립공원은 실제 라이브 스트림입니다. 송출이 끊긴 카메라는 회색 화면이나 "점검 중"으로 표시됩니다.

송출이 없는 명소는 어떻게 확인하나요?

전국 CCTV 허브에서 해당 지역의 CCTV 페이지에서 바로 볼 수 있습니다. 재난포털은 해안·하천 중심으로 전국 45개 지점을 커버합니다.
