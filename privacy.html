이 방침은 GitHub Pages로 호스팅되는 본 사이트의 정보 처리 방식을 설명합니다.

1. 수집하는 정보

  • 방문 통계: 본 사이트는 방문자 수를 집계하는 경량 통계 도구를 사용할 수 있습니다. 쿠키를 사용하지 않는 방식이며, 수집되는 정보는 페이지 조회 수·유입 경로·대략적인 지역(국가 수준) 등 비식별 정보에 한정됩니다.
  • 회원 정보: 본 사이트는 회원가입·로그인 기능이 없으므로 수집하지 않습니다.
  • 결제 정보: 직접 결제·예약을 처리하지 않습니다. 제휴 링크를 통해 외부 예약 사이트로 이동하며, 결제 정보는 해당 외부 사이트의 방침을 따릅니다.

2. 제휴 링크와 외부 서비스

  • 본 사이트는 제휴 마케팅 링크(예약·항공권·투어 등)를 포함할 수 있습니다. 링크를 클릭하면 외부 사이트로 이동하며, 이후 수집되는 정보는 해당 사이트의 개인정보처리방침을 따릅니다.
  • 실시간 카메라·지도·날씨 등 일부 콘텐츠는 외부 서비스(지자체 카메라 서버, 지도 타일 제공자, 날씨 API 등)를 임베드합니다. 이 과정에서 브라우저가 해당 서버에 요청을 보내며, 서버 로그에 IP 주소 등이 기록될 수 있습니다.

3. 쿠키

본 사이트는 자체 광고·추적 쿠키를 사용하지 않습니다. 외부 임베드 서비스(예: 지도, 영상 플레이어)가 자체 쿠키를 설정할 수 있으며, 이는 각 서비스의 정책을 따릅니다.

4. 보관 및 파기

별도의 회원·게시물 데이터베이스가 없으므로 보관하는 개인정보가 없습니다. 통계 도구가 집계하는 비식별 데이터는 서비스 제공자가 정한 보관 기간에 따라 관리됩니다.

5. 이용자의 권리

본 사이트에 직접 제공한 개인정보가 없으므로 열람·정정·삭제 요청 대상이 없습니다. 외부 서비스로 이동한 이후의 정보는 해당 서비스에 문의하시기 바랍니다.
