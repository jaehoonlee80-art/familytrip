아이 동반 여행 짐싸기 — 연령별 필수템과 분리 포장 팁

아이와 여행할 때 짐싸기는 성인 것의 2배입니다. 아래 체크리스트를 따라가면 빠뜨리는 게 없습니다.

👶 영유아 (0~3세)

필수 (분실 시 여행 불가)

  • [ ] 기저귀 + 물티슈 (3일치 × 2배)
  • [ ] 분유/이유식 + 젖병 + 소독제
  • [ ] 아기띠 또는 유모차 (공항에서 대여 가능하면 현지 대여)
  • [ ] 아이 약 (해열제·소화제·밴드·체온계)
  • [ ] 여권 + 항공권 (보호자 지갑에 보관)

위탁 수하물 (공항 분실 시 곤란)

  • [ ] 여벌 옷 3~4벌 (예기치 못한 구토·똥사고 대비)
  • [ ] 수면용품 (담요·베개·인형 — 아이가 익숙한 것)
  • [ ] 목욕용품 (아이 전용 샴푸·바디워시)
  • [ ] 추가 기저귀 (비행기 지연·분실 대비)

🧒 미취학 (4~6세)

필수

  • [ ] 아이 약 (해열제·소화제·밴드·체온계·알레르기약)
  • [ ] 여권 + 항공권
  • [ ] 스킨케어 (자외선 차단제·보습제)
  • [ ] 아이 간식 (비행기·공항 대기용)

위탁 수하물

  • [ ] 여벌 옷 2~3벌
  • [ ] 우비/레인코트 (우천 대비)
  • [ ] 실내화 (호텔·숙소용)
  • [ ] 아이 장난감 2~3개 (비행기·식당 대기용)

🧑 초등 (7~12세)

필수

  • [ ] 아이 여권 (성인과 별도 발급)
  • [ ] 아이 약 (해열제·소화제·밴드·체온계)
  • [ ] 스킨케어 (자외선 차단제·보습제·립밤)

위탁 수하물

  • [ ] 여벌 옷 2벌
  • [ ] 실내화
  • [ ] 충전기 + 보조배터리 (태블릿·게임기용)
  • [ ] 아이 취미 용품 (만화·게임·악기 소형)

✈️ 기내 반입 vs 위탁 수하물 분리 팁

구분 기내 반입 위탁 수하물
항공사 규정 1인 1개 10kg 이내 + 개인가방 1개 1인 23kg 이내
아이 필수품 기저귀·분유·약·여권·간식 여벌 옷·수면용품·장난감
분실 위험 직접 관리 공항 분실 가능성 있음
비행기 지연 대비 즉시 사용 가능 찾기 어려움

팁: 아이 필수품은 기내 반입에, 여벌 옷과 장난감은 위탁 수하물에 넣으세요. 기내 반입이 분실되면 여행이 불가능해집니다.

🧳 분리 포장 방법

  • 파우치/지퍼백: 기저귀·분유·약은 개별 파우치에 — 공항 보안검색 때 꺼내기 편합니다
  • 압축팩: 여벌 옷은 압축팩으로 부피 줄이기 — 캐리어 공간 확보
  • 중복 포장: 아이 옷은 성인 옷과 섞지 말고 별도 파우치 — 빨래할 때 구분 편합니다
  • 무게 분산: 아이 캐리어는 가볍게, 성인 캐리어에 무거운 것 — 공항 이동 시 균형

🌡️ 기후별 추가 팁

  • 더운 지역 (동남아·유럽 여름): 자외선 차단제·모자·선글라스·쿨링 타올 필수
  • 추운 지역 (일본 겨울·유럽 겨울): 아이 방한복·핫팩·목도리·장갑 필수
  • 습한 지역 (동남아): 방수 가방·우비·모기 기피제 필수

✅ 출발 전 최종 체크

  • [ ] 아이 여권/비자 확인 (만료일 6개월 이상)
  • [ ] 항공권·숙소 예약 확인서 인쇄
  • [ ] 여행자 보험 가입 확인
  • [ ] eSIM/유심 준비
  • [ ] 현지 환전 소액 (공항 픽업용)
  • [ ] 아이 약·상비약 챙기기
  • [ ] 유모차·카시트 대여 예약 (필요 시)
  • [ ] 여행 준비 타임라인으로 D-30부터 D-day까지 확인

다음: 여행 준비 타임라인으로 전체 준비 순서 확인, 여행 코스 생성기에서 목적지 검색.
