가족여행 경비 계산기 — 항공·숙소·식비·활동비 총예산 자동 계산

인원과 일수, 여행지를 입력하면 항공·숙소·식비·교통·활동비를 자동으로 나눠 총예산을 계산합니다. 아래 숫자를 바꾸면 결과가 바로 업데이트됩니다.

결과 보는 법

  • 총예산: 항공 + 숙소(일수-1박 기준) + 식비 + 활동비 + 렌터카 + 예비비
  • 1인당 비용: 가족 총액 ÷ (성인 + 어린이 0.7명 환산)
  • 지역별 기본값은 일반적인 가족여행 시세 기준이며, 실제 가격은 항공 특가·성수기·숙소 등급에 따라 크게 달라집니다

예산 줄이는 팁

  1. 항공: 화~목 출발, 2~3개월 전 예약이 유리합니다
  2. 숙소: 에어비앤비/펜션은 4인 이상 가족에게 호텔보다 30~50% 저렴한 경우가 많습니다
  3. 식비: 조식 포함 숙소 + 점심 현지식 + 저녁 배달/간단식 조합이 효율적입니다
  4. 활동: 미리 온라인 예매(클룩·비아토어)하면 현장가 대비 10~20% 절약됩니다
