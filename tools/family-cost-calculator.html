💰 비용 리스트

항공권·숙소·식비·교통·활동비가 포함된 총액입니다. 카드를 누르면 항목별 내역이 펼쳐집니다.

결과 보는 법

  • 총액은 선택한 인원 전체 기준, 1인당은 성인 1명 기준 환산입니다(어린이 60% 가중)
  • 실속형: LCC 항공 + 게스트하우스·펜션 + 현지식 중심 / 균형형: 일반 항공 + 3~4성급 호텔 / 고급형: FSC 직항 + 4~5성급 리조트
  • 우선형은 해당 항목에 예산을 더 배분한 패키지입니다 (예: 항공우선형 = 좋은 좌석·직항, 숙소우선형 = 고급 호텔)
  • 출발일별 가격 차이는 항공권 시세 변동을 반영한 추정치입니다

예산 줄이는 팁

  1. 항공: 화~목 출발, 2~3개월 전 예약이 유리합니다
  2. 숙소: 에어비앤비/펜션은 4인 이상 가족에게 호텔보다 30~50% 저렴한 경우가 많습니다
  3. 식비: 조식 포함 숙소 + 점심 현지식 + 저녁 배달/간단식 조합이 효율적입니다
  4. 활동: 미리 온라인 예매(클룩·비아토어)하면 현장가 대비 10~20% 절약됩니다
